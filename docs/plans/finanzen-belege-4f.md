# Finanzen Scheibe 4f: Steuersätze mit Gültigkeit, Gesamtpreis je Zeile, Eigenbeleg ohne Vorsteuer, Serienerfassung – Umsetzungsplan

Folgt auf [finanzen-belege-4e.md](./finanzen-belege-4e.md), gleicher Branch `finanzen-belege-4b` (ein PR für 4b–4f). Wünsche des
Nutzers vom 20.11.2026 nach den 4e-Checks. Rückfragen beantwortet: Eigenbeleg ohne Vorsteuer **jetzt**; Archivdateien bleiben
(keine Ansicht); Steuersätze **mit Gültigkeit ab Datum**.

**Status: umgesetzt** (Phasen 1-4).

Abweichungen bei der Umsetzung:

- Gesamtpreis ohne Rundungskorrektur: Der Betrag ist exakt der Gesamtpreis, der gerundete Einzelpreis ist nur Info.
- Mitglied: „Gesamt“ gibt es nur bei Ware-Posten; Kategorie-Posten haben dort keine Anzahl.
- `fin_artikel.steuersatz` wird beim Anlegen noch geschrieben (`NOT NULL`), aber nicht gelesen.

## Datenmodell

Migrationen nach der letzten (0236), je mit Down-Datei, DSQL-Regeln (`docs/datenbank.md`):

- `fin_steuersatz_zeitraeume (id text PK, ab date NOT NULL, regel int NOT NULL, ermaessigt int NOT NULL, erstellt_am, erstellt_von)`, Unique-Index `ab` (ASYNC), Seed-Insert der drei Zeiträume.
- `fin_konten.steuersatz_art text NULL` + Backfill (1900→`regel`, 700→`ermaessigt`, 0→`keine`); alte Spalte bleibt, wird nicht mehr gelesen/geschrieben (kein DROP COLUMN).
- `fin_artikel.steuersatz_art text NULL` + Backfill wie oben.
- `fin_belegposten.gesamt_cent bigint NULL` (gesetzt = Gesamtpreis-Zeile; Betrag = gesamt_cent).
- Entwurf-JSON: Posten-Feld `gesamtCent` (nullable).
- Tabellennamen/Spalten an die tatsächlichen Namen anpassen (Konten-Tabelle prüfen).

## Shared

- `steuersaetzeAm(zeitraeume, datum) → { regel, ermaessigt, saetze: number[] }`, `steuersatzFuerArt(art, zeitraum)`, `steuersatzArtVon(satz, zeitraum)`, Schema für Zeiträume; Tests (Grenzen, Covid-Zeitraum).
- `postenBetrag`: mit `gesamtCent` = gesamtCent (Leergut weiter negativ, kein Gesamtmodus); Einzelpreis = `runde(gesamt / anzahl)`.
- `belegPruefen`: Belegdatum nicht in der Zukunft (Fehler), Warnung > 2 Monate (eigene Warnliste wie bestehende Warnungen), Steuersatz gültig am Belegdatum, Anzahl Pflicht.
- `belegBuchungszeilen`: Eigenbeleg → Zeilen ohne Vorsteuer (`steuerArt: 'keine'`, Steuer 0, Betrag brutto); `belegBerechnen` liefert für Eigenbelege Steuer 0.
- Konten-/Artikel-DTOs: `steuersatzArt` statt `steuersatzStandard`/`steuersatz` (Artikel-Vorschläge entsprechend).
- `belegEinreichenSchema`: Belegdatum nicht in der Zukunft.

## API

- Routen `GET /api/finanzen/steuersatz-zeitraeume`, `POST` (neuer Zeitraum), `DELETE /:id` (nur ohne Buchungen im Zeitraum), Rechte wie Kontenplan; Mitglied bekommt die Zeiträume in `einreichungen/auswahl`.
- Konten/Artikel lesen/schreiben `steuersatzArt`; Kassenabrechnung prüft Sätze am Abrechnungsdatum.
- Buchen: Eigenbeleg ohne Vorsteuer; `gesamt_cent` speichern; Datum-Prüfungen; Tests (Eigenbeleg-Zeilen, Gesamtpreis exakt, Covid-Zeitraum, Zukunftsdatum 400).
